# Gitea -> GitHub 自动镜像：定期全量扫描（方案 A，无需 CI）
#
# 安装：crontab -e 追加以下行（替换 <owner> 与脚本绝对路径）。
#   先建日志目录（仅一次）：mkdir -p ~/.local/log
#
#   每天凌晨 3 点扫描一次，为新仓库补齐 GitHub 云端仓库与 Gitea Push Mirror。
#   全量扫描只做初始化（建 GitHub 库 + 配 Push Mirror），已配置好的仓库
#   由 Gitea Push Mirror（sync_on_commit）即时自动同步，无需频繁扫描。
0 3 * * * /usr/bin/python3 /path/to/gitea-push-github/sync/gitea_github_sync.py --repo-owner <owner> >> ~/.local/log/gitea-push-github.log 2>&1
